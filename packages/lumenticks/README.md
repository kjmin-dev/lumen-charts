# lumenticks

An alias of [`@lumen-ticks/core`](https://www.npmjs.com/package/@lumen-ticks/core): the same exports under a short, unscoped name.

Part of [Lumen Ticks](https://github.com/kjmin-dev/lumen-ticks), high-performance financial charts for the web.

```sh
npm install lumenticks
```

```ts
import { createChart } from 'lumenticks';
import ChartWorker from 'lumenticks/worker?worker';
```

`@lumen-ticks/core` is the name the documentation uses. Usage, options and examples are in the [main README](https://github.com/kjmin-dev/lumen-ticks#readme).
