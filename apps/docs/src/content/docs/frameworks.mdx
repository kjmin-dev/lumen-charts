Lumen Charts keeps framework adapters intentionally thin: each adapter creates the chart on mount, forwards option changes to `applyOptions`, and calls `destroy()` on unmount.

**Data always goes through the `ChartApi`**, never through reactive framework props. Passing millions of bars through component props would force unnecessary diffing and allocations on every tick.

Selecting a tab below also selects that framework across [Getting started](/getting-started/) and every [feature guide](/guides/themes/).

## Basic setup & reactive options

Pass display configuration (such as `theme`, `grid`, `crosshair`, `priceScales`, or `localization`) through the wrapper's `options` prop and load data through the `ChartApi` instance:

<Tabs syncKey="framework">
<TabItem label="Vanilla">

<InstallCommand packages="lumen-charts" />

```ts
import { createChart } from 'lumen-charts';

const chart = createChart(document.getElementById('chart')!, { theme: 'dark' });
const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
candles.setData(bars);
chart.timeScale().fitContent();

// Clean up when leaving the page or view:
chart.destroy();
```

</TabItem>
<TabItem label="React">

<InstallCommand packages="@lumen-charts/react react" />

`LumenChart` renders a `<div>` and exposes the `ChartApi` instance through a `ref` (`null` until mounted). Pass a state setter (`ref={setChart}`) when running `useEffect` against the chart so effects fire as soon as the instance is created — including across React `StrictMode` remounts.

```tsx
import type { OhlcColumns } from '@lumen-charts/core';
import { LumenChart, type ChartApi } from '@lumen-charts/react';
import { useEffect, useMemo, useState } from 'react';

export function PriceChart({ dark, bars }: { dark: boolean; bars: OhlcColumns }) {
	const [chart, setChart] = useState<ChartApi | null>(null);
	const options = useMemo(() => ({ theme: dark ? ('dark' as const) : ('light' as const) }), [dark]);

	useEffect(() => {
		if (chart === null) return;
		const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
		candles.setData(bars);
		chart.timeScale().fitContent();
		return () => chart.removeSeries(candles);
	}, [chart, bars]);

	return <LumenChart ref={setChart} options={options} style={{ height: 420 }} />;
}
```

</TabItem>
<TabItem label="Vue 3">

<InstallCommand packages="@lumen-charts/vue vue" />

`LumenChart` exposes the `ChartApi` instance as `chart` on the template ref and deep-watches `:options` to forward updates to `applyOptions`.

```vue
<script setup lang="ts">
import type { OhlcColumns } from '@lumen-charts/core';
import { LumenChart, type ChartApi } from '@lumen-charts/vue';
import { computed, onMounted, useTemplateRef } from 'vue';

const props = defineProps<{ dark: boolean; bars: OhlcColumns }>();
const chartEl = useTemplateRef<{ chart: ChartApi | null }>('chartEl');
const options = computed(() => ({ theme: props.dark ? ('dark' as const) : ('light' as const) }));

onMounted(() => {
	const chart = chartEl.value?.chart;
	if (!chart) return;
	const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
	candles.setData(props.bars);
	chart.timeScale().fitContent();
});
</script>

<template>
	<LumenChart ref="chartEl" :options="options" style="height: 420px" />
</template>
```

`@lumen-charts/svelte` exports the `lumenChart` action. Receive the `ChartApi` once in `onReady`; reactive reads inside `options` flow to `applyOptions` automatically.

```svelte
<script lang="ts">
	import type { OhlcColumns } from '@lumen-charts/core';
	import { lumenChart, type ChartApi } from '@lumen-charts/svelte';

	let { dark = false, bars }: { dark?: boolean; bars: OhlcColumns } = $props();

	function onReady(chart: ChartApi) {
		const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
		candles.setData(bars);
		chart.timeScale().fitContent();
	}
</script>

<div
	style="height: 420px"
	use:lumenChart={{ options: { theme: dark ? 'dark' : 'light' }, onReady }}
></div>
```

		chart.timeScale().fitContent();
	};

}

## Streaming live ticks & indicators

Keep the series handle outside component state and forward incoming ticks straight to `candles.update(tick)`. Your UI framework never re-renders on price ticks, while the data engine updates the bar and every indicator incrementally in one atomic patch:

<Tabs syncKey="framework">
<TabItem label="Vanilla">

```ts
import { createChart, type OhlcBar, type OhlcColumns } from 'lumen-charts';

const chart = createChart(document.getElementById('chart')!, { theme: 'auto' });
const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
candles.setData(history);
candles.addIndicator('ema', { params: { period: 20 } });
chart.timeScale().fitContent();

const stopStream = subscribeTicks('BTCUSD', (tick: OhlcBar) => {
	candles.update(tick);
});

// Later on teardown:
stopStream();
chart.destroy();
```

</TabItem>
<TabItem label="React">

```tsx
import type { OhlcBar, OhlcColumns } from '@lumen-charts/core';
import { LumenChart, type ChartApi } from '@lumen-charts/react';
import { useEffect, useState } from 'react';

const options = { theme: 'auto' as const };

export function LiveChart({ symbol, history }: { symbol: string; history: OhlcColumns }) {
	const [chart, setChart] = useState<ChartApi | null>(null);

	useEffect(() => {
		if (chart === null) return;
		const candles = chart.addSeries('candlestick', { id: symbol });
		candles.setData(history);
		candles.addIndicator('ema', { params: { period: 20 } });
		chart.timeScale().fitContent();

		const stopStream = subscribeTicks(symbol, (tick: OhlcBar) => {
			candles.update(tick);
		});

		return () => {
			stopStream();
			chart.removeSeries(candles);
		};
	}, [chart, symbol, history]);

	return <LumenChart ref={setChart} options={options} style={{ height: 420 }} />;
}
```

</TabItem>

## Subscribing to chart events

Chart events such as `crosshairMove`, `click`, `error`, and `timeScale().subscribe('visibleTimeRangeChange', ...)` return an unsubscribe function. Wire them into reactive state to render custom legends, toolbars, or alerts:

<Tabs syncKey="framework">
<TabItem label="Vanilla">

```ts
import { createChart } from 'lumen-charts';

const chart = createChart(document.getElementById('chart')!);
const legend = document.getElementById('legend')!;

const unsubscribe = chart.subscribe('crosshairMove', event => {
	const bar = event.values.get('BTCUSD');
	legend.textContent =
		bar && 'close' in bar ? `O ${bar.open.toFixed(2)}  H ${bar.high.toFixed(2)}  C ${bar.close.toFixed(2)}` : '';
});

// Call unsubscribe() when no longer needed (or chart.destroy() removes all listeners).
```

</TabItem>
<TabItem label="React">

```tsx
import { LumenChart, type ChartApi } from '@lumen-charts/react';
import { useEffect, useState } from 'react';

export function ChartWithLegend() {
	const [chart, setChart] = useState<ChartApi | null>(null);
	const [readout, setReadout] = useState('');

	useEffect(() => {
		if (chart === null) return;
		return chart.subscribe('crosshairMove', event => {
			const bar = event.values.get('BTCUSD');
			setReadout(
				bar && 'close' in bar ? `O ${bar.open.toFixed(2)}  H ${bar.high.toFixed(2)}  C ${bar.close.toFixed(2)}` : '',
			);
		});
	}, [chart]);

	return (
		<>
			<output>{readout}</output>
			<LumenChart ref={setChart} style={{ height: 420 }} />
		</>
	);
}
```

## Package summary

| Package                | Export        | Props / params                      | Chart access                               | Lifecycle                                  |
| ---------------------- | ------------- | ----------------------------------- | ------------------------------------------ | ------------------------------------------ |
| `lumen-charts`         | `createChart` | `(container, options?)`             | Returned `ChartApi`                        | Manual `destroy()`                         |
| `@lumen-charts/core`   | `createChart` | `(container, options?)`             | Returned `ChartApi`                        | Manual `destroy()`                         |
| `@lumen-charts/react`  | `LumenChart`  | `options?`, `className?`, `style?`  | `ref` (`ChartApi \| null`)                 | `useEffect` mount / unmount (`StrictMode`) |
| `@lumen-charts/vue`    | `LumenChart`  | `options?` (plus fallthrough attrs) | Template ref `{ chart: ChartApi \| null }` | `onMounted` / `onBeforeUnmount`            |
| `@lumen-charts/svelte` | `lumenChart`  | `{ options?, onReady? }`            | `onReady(chart)` callback                  | Svelte action `update` / `destroy`         |
| `@lumen-charts/solid`  | `LumenChart`  | `options?`, `class?`, `onReady?`    | `onReady(chart)` callback                  | `onMount` / `onCleanup` (client-side only) |

Every framework package also re-exports the `ChartApi`, `ChartOptions`, and `DeepPartial` TypeScript types. Core helpers such as `setMaxWorkers` or `PanePrimitive` types can be imported from `@lumen-charts/core` (or `lumen-charts`).

## Adapter tips & SSR

<Aside type="tip" title="React refs and memoized options">
	Use a state callback ref (`const [chart, setChart] = useState<ChartApi | null>(null)` with `<LumenChart ref={setChart} />`) when attaching series or listeners inside `useEffect`. A plain `useRef` is great for reading `chartRef.current` inside click handlers, but updating `ref.current` after mount does not trigger a parent `useEffect`. Also memoize dynamic `options` with `useMemo` (or define static options outside the component) so unrelated renders do not call `applyOptions`.
</Aside>

- **Server-side rendering (SSR)**: Canvases and `ResizeObserver` run in the browser. Mark React components with `'use client'` in Next.js App Router, wrap Vue charts in `<ClientOnly>` in Nuxt, mount Svelte actions on the client in SvelteKit (Svelte actions only execute in the browser), and wrap `@lumen-charts/solid` with `clientOnly()` in SolidStart because it calls `document.createElement('div')` during component setup.
- **Sizing**: Give the chart element an explicit CSS height (`style={{ height: 420 }}`, `style="height: 420px"`, or a CSS class with `height` for Solid). `autoSize` is enabled by default and shares one `ResizeObserver` across all charts on the page.
