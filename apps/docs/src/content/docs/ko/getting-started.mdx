Lumen Charts는 레이어드 HTML 캔버스로 금융 차트를 렌더링하면서 히스토리, LOD 피라미드, 인디케이터 연산은 비동기 데이터 엔진에서 처리합니다.

## 설치

바닐라 TypeScript 또는 JavaScript 프로젝트에서는 기본 패키지를 설치합니다:

<Tabs>
	<TabItem label="pnpm">```sh pnpm add lumen-charts ```</TabItem>
	<TabItem label="npm">```sh npm install lumen-charts ```</TabItem>
	<TabItem label="yarn">```sh yarn add lumen-charts ```</TabItem>
</Tabs>

React, Vue, Svelte, Solid를 사용한다면 각 프레임워크 바인딩 패키지(`@lumen-charts/react`, `@lumen-charts/vue`, `@lumen-charts/svelte`, `@lumen-charts/solid`)를 설치하세요. 자세한 내용은 [프레임워크 바인딩](/ko/frameworks/)을 참고하세요.

## 첫 차트 만들기

컨테이너 요소에 CSS 높이를 지정합니다(`autoSize`가 기본 활성화되어 공유 `ResizeObserver`로 크기를 추적합니다):

```ts
import { createChart } from 'lumen-charts';

const container = document.getElementById('chart')!;
const chart = createChart(container, {
	theme: 'auto', // 'light', 'dark' 또는 prefers-color-scheme 추적
	accessibility: { label: 'BTC/USD 1분봉 시세' },
});

const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });

// 시간은 UTC 밀리초입니다. 대량 히스토리는 컬럼형 TypedArray가 가장 빠르며,
// { time, open, high, low, close } 객체 배열도 받을 수 있습니다.
candles.setData({ time, open, high, low, close });
chart.timeScale().fitContent();

// 데이터 엔진에서 계산되는 인디케이터 추가
candles.addIndicator('bollinger', { params: { period: 20, multiplier: 2 } });
candles.addIndicator('ema', { params: { period: 50 } });

// 실시간 틱: 같은 시간의 마지막 바를 갱신하거나 새 바를 추가합니다.
candles.update({
	time: Date.now(),
	open: 101.0,
	high: 102.0,
	low: 100.5,
	close: 101.4,
});
```

## 비동기 데이터 엔진과 워커

히스토리는 기본적으로 웹 워커 안의 데이터 엔진(`@lumen-charts/engine`)에 저장됩니다. 데이터 메서드는 즉시 반환되며 비동기적으로 반영됩니다:

```ts
candles.setData(history);
await chart.whenIdle(); // 지금까지 전달한 데이터가 화면에 그려지면 resolve
```

페이지의 CSP가 워커를 차단하면 동일한 인터페이스로 메인 스레드 타임슬라이스 모드로 자동 전환됩니다. 필요에 따라 직접 제어할 수도 있습니다:

```ts
// 워커 없이 메인 스레드 타임슬라이스 모드 강제
const localChart = createChart(container, { worker: false });

// 번들러가 앱 코드에서 직접 워커를 생성해야 하는 경우
const bundledChart = createChart(container, {
	worker: () => new Worker(new URL('@lumen-charts/engine/worker', import.meta.url), { type: 'module' }),
});
```
