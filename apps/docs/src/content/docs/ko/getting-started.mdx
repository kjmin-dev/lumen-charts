## 첫 차트 만들기

컨테이너 요소에 CSS 높이를 지정합니다(`autoSize`가 기본 활성화되어 공유 `ResizeObserver`로 크기를 추적합니다). 프레임워크 래퍼는 마운트·반응형 `options` 전달·언마운트 해제를 자동으로 처리하고, 시리즈와 데이터·인디케이터·실시간 틱을 제어할 수 있도록 `ChartApi`를 노출합니다.

<Tabs syncKey="framework">
<TabItem label="Vanilla">

```ts
import { createChart } from '@lumen-ticks/core';

const container = document.getElementById('chart')!;
const chart = createChart(container, {
	theme: 'auto', // 'light', 'dark' 또는 prefers-color-scheme 추적
	accessibility: { label: 'BTC/USD 1분봉 시세' },
});

const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });

// 시간은 UTC 밀리초입니다. 대량 히스토리는 컬럼형 TypedArray가 가장 빠르며,
// { time, open, high, low, close } 객체 배열도 받을 수 있습니다.
candles.setData({ time, open, high, low, close });
chart.timeScale().fitContent();

// 데이터 엔진에서 계산되는 인디케이터 추가
candles.addIndicator('bollinger', { params: { period: 20, multiplier: 2 } });
candles.addIndicator('ema', { params: { period: 50 } });

// 실시간 틱: 같은 시간의 마지막 바를 갱신하거나 새 바를 추가합니다.
candles.update({
	time: Date.now(),
	open: 101.0,
	high: 102.0,
	low: 100.5,
	close: 101.4,
});
```

<TabItem label="React">

```tsx
import type { OhlcColumns } from '@lumen-ticks/core';
import { LumenChart, type ChartApi, type ChartOptions, type DeepPartial } from '@lumen-ticks/react';
import { useEffect, useState } from 'react';

const options: DeepPartial<ChartOptions> = {
	theme: 'auto', // 'light', 'dark' 또는 prefers-color-scheme 추적
	accessibility: { label: 'BTC/USD 1분봉 시세' },
};

export function FirstChart({ bars }: { bars: OhlcColumns }) {
	// ref에 setChart를 전달하면 마운트 직후(StrictMode 포함) effect가 안정적으로 실행됩니다.
	const [chart, setChart] = useState<ChartApi | null>(null);

	useEffect(() => {
		if (chart === null) return;
		const candles = chart.addSeries('candlestick', { id: 'BTCUSD' });
		candles.setData(bars);
		chart.timeScale().fitContent();

		// 데이터 엔진에서 계산되는 인디케이터 추가
		candles.addIndicator('bollinger', { params: { period: 20, multiplier: 2 } });
		candles.addIndicator('ema', { params: { period: 50 } });

		// 실시간 틱: 같은 시간의 마지막 바를 갱신하거나 새 바를 추가합니다.
		candles.update({
			time: Date.now(),
			open: 101.0,
			high: 102.0,
			low: 100.5,
			close: 101.4,
		});

		return () => chart.removeSeries(candles);
	}, [chart, bars]);

	return <LumenChart ref={setChart} options={options} style={{ height: 420 }} />;
}
```

## 비동기 데이터 엔진과 워커

히스토리는 기본적으로 웹 워커 안의 데이터 엔진(`@lumen-ticks/engine`)에 저장됩니다. 데이터 메서드는 즉시 반환되며 비동기적으로 반영됩니다:

```ts
candles.setData(history);
await chart.whenIdle(); // 지금까지 전달한 데이터가 화면에 그려지면 resolve
```

페이지의 CSP가 워커를 차단하면 동일한 인터페이스로 메인 스레드 타임슬라이스 모드로 자동 전환됩니다.

번들러에서 워커 엔트리를 명시적으로 선언하거나 페이지 전체의 워커 수를 제한하려면 앱 진입점에서 `configureWorker(...)`를 한 번만 호출하세요. 모든 패키지가 독립 번들된 `./worker` 엔트리를 직접 제공하므로 `@lumen-ticks/engine`을 따로 설치하지 않아도 Vite `?worker` 생성자, `?url` 문자열, `URL`, 정적 경로, 커스텀 팩토리를 그대로 넘길 수 있습니다. 개별 차트에서는 `worker: false`, `worker: 'dedicated'`, 또는 `createWorkerPool(...)`로 세밀하게 오버라이드할 수 있습니다:

<Tabs syncKey="framework">
<TabItem label="Vanilla">

```ts
import { configureWorker, createChart } from '@lumen-ticks/core';
import ChartWorker from '@lumen-ticks/core/worker?worker'; // Vite (또는 '/assets/lumen-worker.js' / new URL('@lumen-ticks/core/worker', import.meta.url))

// 앱 진입점에서 1회 선언 — 이후 생성되는 모든 차트가 워커 풀을 자동 공유합니다.
configureWorker({ source: ChartWorker, maxWorkers: 2 });

const chart = createChart(container);
const dedicatedChart = createChart(mainContainer, { worker: 'dedicated' });
const localChart = createChart(localContainer, { worker: false });
```

</TabItem>

```tsx
// main.tsx — 앱 진입점에서 1회만 설정합니다.
import { configureWorker } from '@lumen-ticks/react';
```

```tsx
// BundledChart.tsx — 컴포넌트에는 워커 보일러플레이트가 남지 않습니다.
import { LumenChart, type ChartOptions, type DeepPartial } from '@lumen-ticks/react';

const localOptions: DeepPartial<ChartOptions> = { worker: false };

export function BundledChart({ useWorker = true }: { useWorker?: boolean }) {
	return <LumenChart options={useWorker ? undefined : localOptions} style={{ height: 420 }} />;
}
```

## 리소스 정리

바닐라 환경에서는 DOM에서 차트를 제거할 때 `chart.destroy()`를 호출해 캔버스, 옵저버, 이벤트 리스너, 엔진 슬롯을 해제합니다. React, Vue 3, Svelte 5, Solid 바인딩은 언마운트 시 `destroy()`를 자동 호출하므로, 외부 스트림(WebSocket 등)이나 직접 등록한 구독만 정리하면 됩니다.
